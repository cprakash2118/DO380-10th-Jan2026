  - MicroSoft AD (Active Directory)
  
  FYI- OpenShift (Oauth) authenticate users and fetch their attributes from LDAP.
  


POint-02-# LDAP Service Basic.
 - LDAP server stores some attributes(informations):-
   - users 
   - Groups
   - Organizational Units (OU)
   - Attributes (uid,cn,mail etc).
   
   When OpenShift connetc to LDAP server via Oauth server, which perform:
   1- Bind -> Connect to LDAP using admin DN.
   2- search -> Find the users/groups 
   3- Return attributes -> uid,cn,email, etc 
   
 POint-03-# LDAP URI sysntax:-
 
 ldaps://hostname:port/basedn?attributes?scope?filter 
 host:port    -> LDAP server         -> Example:-   idm.ocp4.example.com:389
 basedn       -> Search start point  -> Example:-   cn=administrator,dc=ocp4,dc=example,dc=com 
 attribute    -> Attribute to return -> Example:-   Users, email 
 scope        -> How deep to search  -> Example:-   sub
 filter       -> Search condition    -> Example:-   uid=john 


Final LDAP URL:-
 ldaps://ldap.exampl.example.com/cn=administrator,dc=ocp4,dc=example,dc=com?user?sub?uid
